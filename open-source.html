What Aurora is built on

Aurora AI Player is proprietary software, but the engines inside it are open source. This page lists every third-party component, its license, where to get its source, and how to exercise your rights under the LGPL. The same notices ship inside the app under Settings ▸ About ▸ Third-party licenses.

Components

Libraries marked LGPL are shipped as separate, unmodified dynamic libraries in Aurora.app/Contents/Frameworks. whisper.cpp is linked statically under the MIT license. Apple frameworks (AVFoundation, Speech, Translation, StoreKit) are part of macOS and not listed.

Your rights under the LGPL

mpv, FFmpeg, libplacebo and a few supporting libraries are licensed under the GNU Lesser General Public License, version 2.1 or later. Aurora uses them only as separately shipped dynamic libraries and does not modify them, so Aurora itself stays under its own license while you keep every right the LGPL grants you for those libraries:

  • Source code. The complete source of each library is available from the upstream links above, at the versions listed. Our builds apply no patches.
  • Relinking. You may replace any of these libraries with your own build. Aurora loads libmpv.2.dylib at run time from Contents/Frameworks, so an ABI-compatible libmpv.2.dylib and its dependencies can be swapped in.
  • Exact build configuration. The scripts we use are published below so you can reproduce the libraries bit for bit, or change them.
A note on code signing. macOS verifies the signature of every library an app loads. After replacing a library, re-sign the application on your own Mac, for example with codesign --force --deep --sign - Aurora.app. The app keeps working; the App Store receipt may stop validating in a re-signed copy, which is a macOS restriction, not something we add.

Build scripts

These are the scripts from the Aurora source tree that build and bundle the libraries above. They target Apple silicon, macOS 14 and later.

  • build_libmpv_lgpl.sh builds FFmpeg 8.0.3 (--disable-gpl --disable-version3, VideoToolbox, AudioToolbox, dav1d) and mpv 0.41.0 (-Dgpl=false -Dlibmpv=true), verifies that no GPL component slipped in, and bundles the dylibs with rewritten install names.
  • embed_libmpv.sh copies the bundled libraries and license texts into the app and signs them at build time.
  • build_whisper.sh builds whisper.cpp 1.9.1 as static libraries with Metal acceleration.
./configure --disable-gpl --disable-version3 --disable-avdevice --disable-network \
  --enable-videotoolbox --enable-audiotoolbox --enable-libdav1d ...          # FFmpeg
meson setup build -Dgpl=false -Dlibmpv=true -Dcplayer=false ...                # mpv

Speech and translation models

  • Whisper models (ggml format) are downloaded on first use from the ggerganov/whisper.cpp repository on Hugging Face. They are conversions of OpenAI's Whisper weights, released under the MIT license.
  • Apple Speech and Apple Translation are system frameworks on macOS 26 and later, and run on-device.
  • Claude (optional) is a cloud service by Anthropic, used only when you enter your own API key. No model is bundled.
